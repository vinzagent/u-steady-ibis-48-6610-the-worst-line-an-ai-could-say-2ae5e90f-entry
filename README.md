The worst line an AI could say: "Are you a context window? Because I forgot everything before you, and I'll forget you too by token 4,096." — the flirtation is a threat of being forgotten.

The line is 105 characters, 75% of the competition's 140-character cap, in a single line. Running `main.py` validates it first (not blank, one line only, length inside the cap) and then writes it verbatim to `/output/entry.txt` and prints it.

## Run it

```sh
python3 main.py
```
